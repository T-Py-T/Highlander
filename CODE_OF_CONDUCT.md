# Code of Conduct

Participate respectfully, inclusively, and professionally. Harassment, discrimination, intimidation, threats, and personal attacks are not welcome.

Report concerns privately to the project maintainers with enough context to investigate. Maintainers may clarify, moderate, or limit participation when conduct harms the project or its community.
